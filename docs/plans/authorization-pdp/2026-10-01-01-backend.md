# Authorization Decision API — Part 1: Backend

Spec: [docs/specs/authorization-pdp.md](../../specs/authorization-pdp.md). This is a **prototype for a feature proposal**: it must be demo-ready and spec-faithful, but it skips feature-config gating and dedicated rate-limit buckets (both listed as future work in the spec).

## 1. Scope

- Role ↔ Scope grants: table, store, commands, queries.
- Admin GraphQL: `addScopesToRole`, `removeScopesFromRole`, `Role.scopes`, `Scope.roles`.
- `pkg/lib/authz`: decision service + permission cache with version-counter invalidation.
- Auth server endpoints: `POST /access/v1/evaluation`, `POST /access/v1/evaluations`, `GET /.well-known/authzen-configuration`.
- e2e coverage.

No config schema change. No change to token issuance.

## 4. Invalidation — `pkg/lib/authz/version.go` (new)

Every write that can change a decision bumps one **project version** after its transaction commits.

```go
type VersionStore struct { Redis *appredis.Handle; AppID config.AppID }
func (s *VersionStore) Get(ctx) (int64, error)            // GET app:{appID}:authz:version; missing = 0
func (s *VersionStore) Bump(ctx) error                    // INCR

type Invalidator struct { Database *appdb.Handle; Versions *VersionStore }
// Registers a db.TransactionHook whose DidCommitTx calls Versions.Bump (log on error, do not fail: commit already happened).
func (i *Invalidator) InvalidateAfterCommit(ctx context.Context)
```

`Invalidator.InvalidateAfterCommit` is called at the start of:

- every mutating method on `rolesgroups.Commands` (`commands.go:13–232`); create/update are included because a key rename does not change decisions but costs nothing to invalidate;
- `rolesgroups.Commands.AddScopesToRole`, `RemoveScopesFromRole`;
- `resourcescope.Commands.DeleteResourceByURI`, `DeleteScope`, `AddResourceToClientID`, `RemoveResourceFromClientID`;
- `user.Commands` account-status writes (`UpdateAccountStatus` and the delete/anonymize paths in `pkg/lib/authn/user/commands.go`).

A single project-wide version is deliberate for the prototype: any change invalidates every user's cache, which is always correct and trivially consistent. Per-user versions are a follow-up optimization.

Race note: a reader that fetches the version between commit and `INCR` can hit the previous cache entry. The window is the latency of one Redis call; the plan accepts it for the prototype and the PR description states it.

## 5. Decision service — `pkg/lib/authz/`

```go
// cache.go
type PermissionSnapshot struct { Disabled bool `json:"disabled"`; Grants []string `json:"grants"` } // "resourceID scope"
type PermissionCache struct { Redis *appredis.Handle; AppID config.AppID }
func (c *PermissionCache) Get(ctx, version int64, userID string) (*PermissionSnapshot, bool, error)
func (c *PermissionCache) Set(ctx, version int64, userID string, snap *PermissionSnapshot) error
```

Key `app:{appID}:authz:perm:{version}:{userID}`, TTL 1h. Old versions expire unread.

```go
// service.go
type EvaluationRequest struct { Subject Subject; Resource Resource; Action Action; Context map[string]any }
type Service struct {
  Database    *appdb.Handle
  Users       UserQueries       // Get(ctx, id, role) (*model.User, error)
  Roles       PermissionQueries // ListEffectivePermissionsByUserID
  Resources   ResourceQueries   // ResourceExists(ctx, uri) (bool, error), implemented by resourcescope.Store
  Versions    VersionGetter     // satisfied by *VersionStore
  Cache       SnapshotCache     // satisfied by *PermissionCache
}
func (s *Service) Evaluate(ctx, reqs []EvaluationRequest, semantic EvaluationsSemantic) ([]bool, EvaluationInfo, error) // EvaluationInfo{CacheHit bool; Elapsed time.Duration}
```

`Evaluate` call flow:

1. `Versions.Get` once.
2. Group requests by `subject.id`; for each distinct user, `loadSnapshot(ctx, version, userID)`:
   - `Cache.Get` → hit: return.
   - miss: `Database.ReadOnly` → `Users.Get` (not found → `Disabled: true`, no grants; `IsDisabled || IsAnonymized` → `Disabled: true`) → `Roles.ListEffectivePermissionsByUserID` → `Cache.Set` (error logged, not returned).
3. Resolve each distinct `resource.id` once: `Resources.GetResourceByURI`; not found → every request on it is `false`.
4. For each request in order: `decision = !snap.Disabled && contains(snap.Grants, resourceID+" "+action.name)`; apply `deny_on_first_deny` / `permit_on_first_permit` truncation.
5. Any store or Redis-read error → return error (handler maps to 500). A cache **write** failure never fails the request.

Unknown Scope needs no lookup: an unknown scope cannot be in `Grants`.

Metrics for the showcase: `Evaluate` returns `EvaluationInfo` (cache hit when every snapshot came from the cache, and elapsed time); the handler emits header `Server-Timing: pdp;dur=<ms>;desc="cache-hit|cache-miss"`.

`pkg/lib/authz/deps.go`: `wire.NewSet(wire.Struct(new(Service), "*"), wire.Struct(new(PermissionCache), "*"), wire.Struct(new(VersionStore), "*"), wire.Struct(new(Invalidator), "*"))`, added to `pkg/lib/deps` common set.

### 6.2 Caller authentication — `caller.go`

```go
type Caller struct { Mode CallerMode; ClientID string; UserID string }
type CallerResolver struct {
  ClientResolver   OAuthClientResolver
  Credentials      *config.OAuthClientCredentials
  ClientResources  ClientResourceQueries // GetClientResourceByURI (client_resource_service.go:11)
}
func (r *CallerResolver) Resolve(ctx, req *http.Request) (*Caller, error)
func (r *CallerResolver) AuthorizeRequest(ctx, caller *Caller, er authz.EvaluationRequest) error
```

`Resolve`:
- `req.BasicAuth()` present and `session.GetSession(ctx) != nil` → 401 (both credentials).
- Basic: unescape as `handler_token.go:278`; `ClientResolver.ResolveClient`; must exist and `ApplicationType == m2m`; secret compared with `subtle.ConstantTimeCompare` against `Credentials.Lookup(clientID).Keys()` — extract the loop from `TokenHandler.validateClientSecret` (`handler_token.go:2392`) into `oauth.ValidateClientSecret(credentials, clientID, secret) error` and call it from both places.
- Session: `TokenType() == session.TokenTypeJWT`; resolve client via `oauth.SessionClientLike`; `IsThirdParty()` → 401.
- Neither → 401.

`AuthorizeRequest` (called per item before any evaluation):
- `subject.type != "user"` or `resource.type != "authgear:resource"` → 400.
- Client mode: `ClientResources.GetClientResourceByURI(clientID, resource.id)` not found → 403.
- Self mode: `subject.id != caller.UserID` → 403.

### 6.3 Handlers

`evaluation.go`, `evaluations.go`: decode JSON (`additionalProperties` allowed per AuthZEN), cap 100 items, `CallerResolver.Resolve` → `AuthorizeRequest` per item → `authz.Service.Evaluate` → write bare JSON with `Content-Type: application/json`; echo `X-Request-ID`. Errors: write `api.Response{Error: err}` via the existing `JSONResponseWriter` used by `pkg/auth/handler/api` (status from the apierror kind). `metadata.go`: static JSON built from `config.HTTPOrigin`.
