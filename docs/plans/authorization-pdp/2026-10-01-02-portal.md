# Authorization Decision API — Part 2: Portal

Depends on Part 1 commit 2 (Admin API schema). Follow the `update-portal-ui` and `add-portal-admin-api-query` / `add-portal-admin-api-mutation` skills.

## 1. Scope

A **Permissions** tab on the Role details screen: for every Resource in the project, list its Scopes with a checkbox meaning "this role holds this permission". Saving diffs the checked set against the loaded set and calls `addScopesToRole` / `removeScopesFromRole` per Resource.

The screen fetches only what it shows: Resources page by page, and for each expanded Resource, its Scopes plus `role.scopes(resourceURI:)` — never the full scope list of every Resource up front.
